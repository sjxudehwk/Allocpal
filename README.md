# Allocpal
AllocPal is an AI-powered group work platform that ensures fair task allocation and transparent contribution tracking. It uses Google Gemini to break down projects, assign tasks based on team size, skills, and deadlines, and track real-time progress so every member contributes equally—no free riders, no burnout.
## Problem
Group projects often become unfair, with unequal workload distribution and lack of accountability.

## Solution
AllocPal uses AI to automatically allocate tasks fairly, track real-time progress, and provide contribution insights so every team member participates equally.

## Key Features
- Firebase Authentication
- Project creation with team members & deadlines
- AI-powered task breakdown and assignment (Google Gemini)
- Task progress tracking (per member)
- Fairness & contribution insights
- Join projects via unique code

## Tech Stack
- Frontend: React
- Backend: Firebase Auth & Firestore
- AI: Google Gemini
- Platform: Base44
